# Прогноз РТО магазинов Пятёрочка

Проект для соревнования X5 Group по прогнозированию розничного товарооборота магазинов Пятёрочка на ноябрь.

РТО - это месячная выручка магазина. В данных есть история по 20615 магазинам за 10 месяцев, а задача состоит в том, чтобы построить прогноз на 11-й месяц и сформировать файл test.csv с колонками new_id и rto.

## Что сделано

- Проведён базовый аудит данных: размеры таблиц, пропуски, дубли, полнота истории по магазинам.
- Проверено, что test['rto'] - это шаблонный baseline, а не реальные ответы.
- Сделан EDA по динамике РТО, дневному РТО, месячным темпам роста, сегментам магазинов и резким скачкам.
- Построена rolling validation: модель проверяется на известных будущих месяцах без утечки данных.
- Собраны признаки из прошлого: лаги РТО, дневной РТО, rolling-статистики, ratios, календарные и статичные признаки магазина.
- Проверены несколько моделей: HistGradientBoosting, ExtraTrees, LightGBM, XGBoost и CatBoost.
- Итоговый прогноз построен ансамблем лучших моделей.

## Итог

Финальный submission набрал **95.2 балла** в системе соревнования.

Итоговый подход:

- HistGradientBoosting
- ExtraTrees
- XGBoost
- weighted ensemble с весами 0.5 / 0.4 / 0.1
